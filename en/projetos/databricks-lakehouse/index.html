Problem

A large analytics platform needs someone to check, with evidence, whether what was delivered is what was claimed, and whether an assistant answering in natural language gets the numbers right. That is my role on the project: auditor and task executor.

Data and scale

  • Medallion architecture (bronze, silver, gold) on Azure Databricks, with Unity Catalog and Delta Lake.
  • Tables of up to about 2 billion rows in the layers I audit.

Approach

  • Read-only technical audit of a sprint's executions, from the catalog, Delta history, query history, jobs and code.
  • Audit report, per-task decision matrix and flowcharts.
  • Review of transformation, aggregation and quality rules between layers, with proposed fixes.
  • Data dictionary for the platform's datasets.
  • Natural language to SQL assistants (Genie): a semantic layer with Metric Views as the single source for dashboard and assistant, instructions with no hard-coded numbers, examples and parameterized trusted queries.
  • I treated each assistant as a model to validate: questions with no example, ground truth computed in SQL, and regression and tuning rounds, always in a test copy.
  • Method finding: the data source exposed to the assistant matters more than the instruction. Restricting sources to the semantic layer fixed failures no prompt tweak could.

How I validated it

  • Acceptance test with known-answer questions: each assistant answer is compared with ground truth computed in SQL, with regression rounds after every change.
  • Every audit claim linked to evidence pulled from the environment, versioned and permalinked.

Result

  • Audit report, decision matrix and document index delivered.
  • Documentation routine with versioned evidence adopted as the team guide.
  • Reconfigured assistant passed the acceptance test, in a test environment.
