Bandit: an AI agent on WhatsApp, piloting at Unimontes

An AI agent on WhatsApp that answers students' questions from the course's own teaching material and shares grades and attendance only with the student they belong to. Currently piloting at Unimontes, with Marcelo&Co.

Context

A professor and their class needed an assistant that could answer questions about the course at any hour without exposing one student's data to another. I built the agent with Marcelo&Co, which is taking it through a pilot at Unimontes.

What I did

  • Designed the architecture and wrote most of the code: course material in vector search, and each student's data in PostgreSQL, outside the vector store.
  • Built the RAG over the syllabus material, citing source, chapter and page in each answer, with class filtering done on the server.
  • Built the output filter that blocks any answer containing another student's data and logs each block as an incident for the professor.
  • Built the professor portal (Spring Boot and React), where teaching staff upload material and follow the class.
  • Wrote the student isolation test suite, run against a real database on every push.

How it works, in four stages

  1. Channel

    • WhatsApp (Evolution API)
    • Professor portal

  2. Knowledge

    • Syllabus and material
    • Docling + Qdrant

  3. Core

    • Tool-using agent
    • Student PostgreSQL

  4. Guard

    • Output filter
    • Isolation tests

Method

  • RAG over teaching material only: individual student data never goes into a vector store.
  • Independent barriers between students: tools with no student parameter, individual data kept out of the vector store, and an output filter.

Result

  • Piloting at Unimontes, serving students over WhatsApp.
