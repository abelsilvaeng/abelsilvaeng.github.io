Bandit: a RAG AI agent on WhatsApp

Together with a university professor, I built an AI agent that serves students on WhatsApp: it answers course questions with RAG over the course material, citing source, chapter and page, and gives grades and attendance only to the student who asks. Piloting at Unimontes, a state university, with Marcelo&Co.

Problem

A professor and a class needed an assistant available at any hour, answering about course content and each student's standing, without one student's data ever reaching another.

Data and scale

  • Knowledge: course syllabus material converted with Docling and indexed in Qdrant, with source, chapter and page.
  • Individual data: grades, attendance and deadlines in PostgreSQL, outside the vector store.

Approach

  • Separation by design: course material in vector search; individual data never goes into a vector store.
  • Agent tools take no student parameter: identity comes from the channel, not from the question text.
  • The database enforces Row-Level Security per session, and the grade enters the answer only after generation, through a placeholder: the value never goes through the model.
  • Class filter applied on the server and answers that cite source, chapter and page.
  • Output filter that stops answers in which it detects another student's data and logs the case as an incident for the professor.
  • Professor portal in Spring Boot and React to upload material and follow the class.

How I validated it

  • Nearly 500 automated tests, with a cross-student leakage suite against a real database on every push (GitHub Actions).
  • Mutation tests that deliberately disable each safeguard to prove the suite turns red.
  • End-to-end tests with the real model: no grade in the prompt and classmates' data stopped by the output filter.
  • Layered isolation barriers: tools with no student parameter, a server-side class filter and an output filter, all covered by the test suite.

Result

  • Piloting at Unimontes, serving students on WhatsApp.

Architect and author of most of the code: agent, RAG, student database, output filter, tests and portal. Marcelo&Co runs the pilot with Unimontes.
