APIGEO: the geolocation API behind Projeto Mapear

The API that turns a field coordinate into federal highway, kilometer marker, municipality and PRF unit, always against the current official road network.

13,758locations mapped in Mapear's 11th edition, which uses the API in production

Where
Polícia Rodoviária Federal (PRF), Brazil's federal highway police
Period
2025 - present
Role
Senior Data Scientist, contractor serving PRF/DTIC (the agency's IT and communications directorate)

Context

Projeto Mapear is the PRF program that, since 2003, has identified places along federal highways where children and adolescents are vulnerable to sexual exploitation. It was recognized by the UN Security Forum in 2012. For it to work, every field record has to become a highway, a kilometer marker, a municipality and a responsible unit, consistent with the official network.

What I did

  • Designed and built the API in FastAPI on PostGIS, with two services: lookup by coordinate and lookup by state, highway and kilometer.
  • Modeled the spatial database with the national road network (SNV, from DNIT, Brazil's federal transport infrastructure agency), IBGE municipal boundaries and PRF operational units.
  • Automated the data updates: each new release is detected, downloaded, loaded, validated inside the database and switched on in a single transaction.
  • Put load quality control inside the database: a failed load never goes live and the current release stays in place.
  • Designed the cache with a key versioned by all three datasets, so a release switch never serves a stale answer.
  • Validated responses field by field against reference records and shipped the API through the corporate gateway and CI/CD pipeline.

How it works, in four stages

  1. Spatial database

    • Road network (SNV)
    • Municipal boundaries (IBGE)
    • Operational units

  2. Updates and cache

    • One updater per dataset
    • In-database validation
    • Transactional switch
    • Versioned cache

  3. API and gateway

    • By coordinate
    • By state, highway and km
    • Gateway authentication

  4. Field

    • Field record
    • Highway, km, municipality, unit

Method

  • Proximity queries on geography with a GiST index, in SIRGAS 2000
  • Linear referencing: snapping the point to the road segment and interpolating the kilometer
  • Stable-name views over one table per release, with transactional switch
  • Load validation by volume, reference system, state coverage and geometry

Result

  • API in production at PRF, used by Projeto Mapear.
  • Automatic updates in place for the road network, municipal boundaries and operational units.
  • Mapear in public numbers: running since 2003; 11th edition in 2025/2026; 13,758 mapped locations; 4 risk levels. Source: the project's official page.
  • The awards and honors belong to the project, which is over 20 years old. The API is my technical contribution to it. No mapped location is shown here.
