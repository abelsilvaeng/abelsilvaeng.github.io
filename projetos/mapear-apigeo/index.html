APIGEO: a API de geolocalização que serve o Projeto Mapear

A API que transforma uma coordenada de campo em rodovia federal, quilômetro, município e unidade da PRF, sempre sobre a malha oficial vigente.

13.758pontos mapeados na 11ª edição do Mapear, que consome a API em produção

Onde
Polícia Rodoviária Federal
Período
2025 - hoje
Papel
Cientista de Dados Sênior, prestador de serviço à PRF/DTIC (Diretoria de Tecnologia da Informação e Comunicações)

Contexto

O Projeto Mapear é o programa da PRF que, desde 2003, identifica nas rodovias federais os locais vulneráveis à exploração sexual de crianças e adolescentes. Recebeu o reconhecimento internacional do Fórum de Segurança da ONU em 2012. Para funcionar, cada registro de campo precisa virar rodovia, quilômetro, município e unidade responsável, de acordo com a malha oficial.

O que fiz

  • Projetei e construí a API em FastAPI com PostGIS, com dois serviços: localização por coordenada e localização por UF, BR e km.
  • Modelei o banco espacial com o SNV do DNIT, a malha municipal do IBGE e as unidades operacionais da PRF.
  • Automatizei a atualização das bases: cada nova edição é detectada, baixada, carregada, validada no próprio banco e ativada numa única transação.
  • Coloquei o controle de qualidade da carga dentro do banco: carga reprovada não entra e a edição vigente continua valendo.
  • Desenhei o cache com chave versionada pelas três bases, para que a troca de edição nunca sirva resposta antiga.
  • Validei as respostas campo a campo contra registros de referência e publiquei a API pelo gateway e pela esteira corporativa.

Como funciona, em quatro etapas

  1. Banco espacial

    • SNV (DNIT)
    • Malha municipal (IBGE)
    • Unidades operacionais

  2. Atualização e cache

    • Atualizadores por base
    • Validação no banco
    • Troca transacional
    • Cache versionado

  3. API e gateway

    • Por coordenada
    • Por UF, BR e km
    • Autenticação no gateway

  4. Campo

    • Registro de campo
    • Rodovia, km, município, unidade

Método

  • Consulta de proximidade em geography com índice GiST, em SIRGAS 2000
  • Referência linear: localização do ponto sobre o trecho e interpolação do km
  • Views de nome estável sobre uma tabela por edição, com troca transacional
  • Validação de carga por volume, sistema de referência, cobertura de UFs e geometria

Resultado

  • API em produção na PRF, consumida pelo Projeto Mapear.
  • Atualização automática das bases do SNV, do IBGE e das unidades operacionais implementada.
  • O Mapear em números públicos: desde 2003; 11ª edição em 2025/2026; 13.758 pontos mapeados; 4 níveis de risco. Fonte: página oficial do projeto.
  • Os prêmios e o reconhecimento são do projeto, que tem mais de 20 anos. A API é a minha contribuição técnica a ele. Nenhum ponto mapeado aparece aqui.
